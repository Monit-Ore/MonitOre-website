SOBRE O PROJETO

Nosso projeto foi desenvolvido para realizar o monitoramento contínuo da infraestrutura computacional dos IHMs utilizados nas torres de extração. Por meio da coleta periódica de indicadores essenciais de hardware, como consumo de CPU, memória RAM e armazenamento em disco.

Ao transformar métricas técnicas em informações estratégicas, o sistema reduz a dependência de manutenções exclusivamente reativas, garantindo maior disponibilidade, segurança e continuidade operacional para o setor de mineração.

O sistema realiza a coleta periódica das métricas de hardware das máquinas supervisoras das torres de extração. Esses dados são enviados para a plataforma web, onde podem ser acompanhados por meio de gráficos e históricos.

A partir dessas informações, o sistema identifica condições anormais, como uso elevado de CPU, memória ou armazenamento, e pode gerar alertas para que a equipe consiga agir antes que o problema evolua para uma falha.

POR QUE ESSA SOLUÇÃO?

O objetivo não é apenas acompanhar números, mas transformar os dados coletados em informações úteis para a tomada de decisão. Com o monitoramento contínuo, a equipe consegue identificar sinais de degradação, reduzir o tempo de diagnóstico e agir de forma preventiva, contribuindo para maior disponibilidade e confiabilidade dos sistemas das torres de extração.
